# v0.5.3 — Windows「開始」功能表捷徑圖示修正版

本版修正 Windows 11「開始」功能表仍把遊戲捷徑顯示成空白文件圖示的問題。遊戲、
繁中內容、原生解析度戰鬥修正與 Windows x86 runtime 均與 v0.5.2 相同。

## 主要變更

- 不再要求 Windows Shell 從舊 SDL 執行檔的資源索引擷取捷徑圖示。該圖示雖會在
  工作列右鍵選單顯示，卻未必能由 Windows 11「開始」功能表可靠解析。
- 安裝器現在把包含 16、32、48 與 128 像素尺寸的專用多解析度圖示安裝為
  `C:\Games\UQM-HD-TW\uqm-hd-zh-tw.ico`，並讓桌面與「開始」功能表捷徑明確使用
  `uqm-hd-zh-tw.ico,0`。
- 新圖示使用未曾被舊版捷徑引用的檔名，可避開 Windows 對先前空白圖示路徑留下的
  快取。升級時仍保留同一個繁中全螢幕啟動名稱與參數。
- 本機既有的工作列釘選亦已同步到同一個專用圖示；安裝器只管理桌面與「開始」
  功能表捷徑，不會任意改寫其他使用者自行建立的釘選。

- 67 項 Python 本地化、資產、輸入、原生戰鬥座標、封裝與安裝生命週期回歸測試。
- Windows PowerShell 管理式升級、11,474 個管理檔案的完整雜湊與兩個捷徑驗證。
- 「開始」功能表與既有工作列釘選均指向相同的繁中全螢幕啟動目標、參數及

  安裝後亦已清除並重新整理 Shell 圖示快取。
