# v0.3.2 — Super Melee 船艦資料滑鼠操作與面板細節修正

本版讓 Super Melee 選船器與船艦資料頁的滑鼠操作完整銜接，修正船艦資料頁
「船員／能量」（原 `CREW`／`BATT`）標籤的背景及邊界，並把 README 船艦圖鑑
整理成單一、不折疊的完整表格。

## 主要變更

- Super Melee 選船器兩側的 `PICK SHIP`／`SHIP INFO` 標籤現在可直接以滑鼠
  點選，行為分別等同按下 `Enter`／`Alt`。
- 開啟船艦資料頁後，在可視船艦資料範圍內任意按一下滑鼠左鍵即可返回選船器。
- 船艦資料頁的點擊世代與去彈跳狀態只在該模式建立及消耗；返回後不會把同一次
  點擊傳入選船器，也不影響其他遊戲畫面。
- 船艦資料頁的 `CREW`／`BATT` 已本地化為「船員／能量」。產生器會取樣相鄰
  面板的實際背景色，並把文字限制在量表下方；1x、2x、4x 的量表、右側分隔線
  及底部分隔線均保留原始像素，不再被清除矩形覆蓋。
- README 船艦圖鑑改為單一、永遠展開的 26 艘船艦表格：25 艘 Super Melee
  船艦加上戰役專用先驅者旗艦。每列都包含船艦圖片、繁體中文與英文名稱、完整
  明列數值、武器、特殊能力、策略、優勢與弱點。
