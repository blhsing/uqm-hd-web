# v0.2.0 — Super Melee 繁中介面與雙人操作指南

此版本完整本地化 Super Melee 隊伍設定畫面的可見介面，並改善戰鬥 HUD
中「船員／能量」的字重。發行 ZIP 不含原版遊戲或獨立的已修改
`uqm.exe`；請先從官方 SourceForge 專案取得 Windows Beta 1。

## 新增與改善

- `SUPER-MELEE` 標題改為「超級對戰」。
- 右側玩家、簡易／普通／最強電腦、網路、儲存、載入、開戰及離開項目
  均已本地化，並保留原版角色、金屬框與選取光效。
- 1x／2x／4x 的「船員／能量」各自使用固定光學尺寸；4x 採較輕的
  Noto Sans TC Regular/400，密集中文字不再糊成厚重色塊。
- README 新增玩家二獨立操作表：玩家二控制上方隊伍，以 `E/D/S/F`
  選船、`Q` 確認；戰鬥中以 `E` 推進、`S/F` 轉向、`Q` 主武器、`A`
  特殊能力。
- 新增可重現的 PSD 擷取工具與無文字 Super Melee 來源底圖，方便後續
  重新產生三種解析度的介面資源。

## 驗證範圍與限制

本版本通過 23 項本地化測試，以及安裝後 13 項完整驗證：11,530 個管理
檔案、三個 UQM 套件、五個捷徑及 4x 1920×1080 全螢幕煙霧測試。
另以實際 4x Super Melee 流程確認繁中隊伍設定、玩家二戰鬥輸入、較輕的
「船員／能量」狀態字，以及 `Esc` 返回隊伍設定功能。

英文原聲沒有重新配音；少數執行檔硬編碼詞仍為英文；翻譯尚未完成逐句
母語人工校訂及完整劇情通關；網路 Super Melee 尚未驗證。
