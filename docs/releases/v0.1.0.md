# v0.1.0 — 首個公開繁體中文版本

這是《The Ur-Quan Masters HD Beta 1》非官方繁體中文版本的首次公開發行。
發行 ZIP 不含原版遊戲或獨立的已修改 `uqm.exe`；請先從官方 SourceForge
專案取得 Windows Beta 1。

## 內容

- 107 份資源文件中全部 5,177 筆可翻譯記錄的 LLM 繁中翻譯。
- 已本地化的五個主選單選項及明顯的黃色選取脈衝。
- Noto Sans TC 衍生的可讀點陣字型、放大的 `船員`／`能量` HUD 標籤。
- 1x、2x、4x 星圖按鍵說明，以及推薦的 4x 全螢幕捷徑。
- 修正開始新遊戲後黑畫面的套件結構。
- 本機 Super Melee 中只有 `Esc` 會結束目前一局並返回隊伍設定。
- 管理式 Windows 安裝、雜湊鎖定 PE 補丁、完整安裝驗證及重建工具。
- 繁中完整玩法指南，以及 25 艘 Super Melee 船艦與戰役旗艦的圖文說明。

## 驗證範圍與限制

本版本通過 19 項本地化測試、11,530 個管理檔案雜湊、三個 UQM 套件、
五個捷徑及 4x 1920×1080 全螢幕煙霧測試。英文原聲沒有重新配音；少數
執行檔硬編碼詞仍為英文；翻譯尚未完成逐句母語人工校訂及完整劇情通關；
網路 Super Melee 尚未驗證。
