# v0.4.0 — 4x 細緻字型與原生解析度全螢幕版

本版停止提供 1x／2x 繁中資產，將遊戲統一為一個自足的 4x 套件，並針對高解析度
全螢幕重新產生所有含本地化文字的圖像資產。安裝器會偵測主螢幕原生解析度；在本次
實機驗證的 1920×1080 螢幕上，遊戲以 1920×1080 全螢幕輸出，4:3 遊戲畫面保持
正確比例並置中顯示。

## 字型與圖像

- 所有遊戲內繁中文字形改用 Noto Sans TC Medium/500 TrueType 輪廓，以最終尺寸的
  四倍進行光柵化，再以 Lanczos 縮小，讓細筆畫、字腔及斜線比舊點陣結果清楚。
- 新增低透明度邊緣清理及固定 HUD 欄位的安全留白，避免太陽、月份、船長、船名、
  燃料與船員等字樣被裁切。
- 重新產生 4x 主選單、超級對戰設定畫面、星圖按鍵說明、船艦選擇面板、戰鬥中的
  「船員／能量」標籤，以及 25 張 1280×960 繁中船艦資料頁。
- 戰鬥狀態標籤保留原版灰色面板底色，使用較輕的 350 字重；主選單則維持清楚但不
  過粗的 Medium/500。

## 解析度與安裝

- 發行包只含 `hires4x-zh_TW.uqm`；1x 與 2x 模式及其捷徑不再受支援。
- 桌面與開始選單捷徑會以 Windows 回報的主螢幕原生解析度、全螢幕、4x 邏輯 UI
  及最近鄰縮放啟動。安裝目錄另保留一個 1280×960 的 4x 視窗模式捷徑。
- 從舊版升級時，只有先前管理式安裝明確擁有且雜湊仍相符的 1x／2x 套件與舊捷徑
  會被移除；設定、存檔及無關檔案均保留。
- 安裝後驗證器同樣動態偵測原生解析度，不再把 1920×1080 寫死為所有電腦的預期值。
