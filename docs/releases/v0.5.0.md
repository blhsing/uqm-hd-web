# v0.5.0 — 原生 1080p 超取樣版

本版以此主機的 1920×1080 全螢幕為唯一發行目標，移除 1x、2x 與 4x 啟動模式。
引擎先在 2560×1920 的 4:3 邏輯畫布繪圖，再由 OpenGL 雙線性縮小至
1440×1080 並置中；左右保留黑邊，因此畫面不會變形，也不再以最近鄰方式放大像素。

## 主要變更

- 新增解析度因子 3；開始選單捷徑固定使用 `--resfactor=3`、`-c bilinear`、
  `-f` 與主螢幕原生解析度。
- 本地化套件改名為 `native1080-zh_TW.uqm`；舊的 1x、2x、4x 套件與捷徑會由
  管理式升級流程安全移除。
- 所有繁中文字型、主選單、超級對戰介面、星圖說明、船艦選擇面板、戰鬥 HUD
  與 25 張船艦資料頁均以新邏輯解析度重新產生。
- 沒有原生第六組圖框的上游 4x PNG 會先轉為 32 位元表面，再以透明度安全的
  雙線性演算法放大至 2560×1920 邏輯尺寸；OpenGL 最終縮小提供抗鋸齒效果。
- OpenGL 後端使用可容納 2560×1920 畫布的 4096×2048 動態紋理，並檢查顯示卡
  回報的最大紋理尺寸。
- Windows x86 建置在 GCC 16 使用 linker response file，避免舊建置系統超出
  Windows 命令列長度。
- 煙霧測試會拒絕未知位元深度或失敗的圖像格式轉換診斷。

  1440×1080 4:3 viewport。
