# v0.5.1 — 全螢幕輸入與截圖修正版

本版延續 v0.5.0 的原生 1920×1080 超取樣發行目標，修正獨佔全螢幕下的滑鼠游標與
`PrtScr` 行為，並簡化開始選單名稱。

## 主要變更

- 點擊不再隱藏硬體游標，因而不會觸發部分 SDL／Windows 顯示驅動把游標恢復到
  畫面中央；鍵盤輸入仍會隱藏游標，移動或點擊滑鼠則會顯示並保留游標原位。
- `PrtScr` 直接讀取 OpenGL back buffer，修正上下方向後複製為 Windows DIB 至
  剪貼簿，並同步儲存 32 位元 BMP 至
  `%APPDATA%\UQM-HD-zh_TW\screenshots`。此路徑不依賴 Windows Graphics Capture，
  因此獨佔全螢幕仍可擷取完整 1920×1080 畫面。
- 開始選單捷徑改名為
  `The Ur-Quan Masters HD - Traditional Chinese`；啟動參數仍包含 `-f`，維持
  主螢幕原生解析度全螢幕。升級器只在舊捷徑列於前一份受管理 manifest 時移除
  `(Fullscreen)` 舊名稱。

- 66 項 Python 本地化、資產、輸入、封裝與安裝生命週期回歸測試。
- Windows PowerShell 管理式升級、11,473 個管理檔案的完整雜湊與兩個捷徑驗證。
