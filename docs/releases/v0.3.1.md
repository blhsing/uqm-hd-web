# v0.3.1 — Super Melee 選船、船艦資料與狀態標籤完整繁中化

本版補齊 Super Melee 選船流程的影像本地化，修正船名末字被顯示成小圓圈，並讓
戰鬥中的「船員／能量」保留原版灰色面板背景。Windows x86 執行環境沿用 v0.3
來源建置版本；更新集中在三個繁中內容套件、產生工具、驗證規則及說明文件。

## 主要變更

- 「小圓圈」並非缺字：舊翻譯把英文縮寫欄位 `Chenje.` 直譯成 `陳傑。`，其中
  `。` 就是畫面上的圓點。本版讓 16 個縮寫欄位一律重用完整中文船名，陳傑蘇
  育巢艦會完整顯示為「陳傑蘇」。驗證器亦會拒絕再次出現這類縮寫翻譯。
- Super Melee 編組視窗中的 `PICK SHIP`、`SHIP INFO` 及 Project 6014 提示已
  本地化為「選擇船艦」、「船艦資料」及繁中說明。
- 25 艘船艦的資料頁全部改為繁體中文，包含船員、能量、費用、極速、加速、
  轉向、回能、武器、特殊能力與戰術。每頁同時產生 1x、2x、4x 原生解析度影像：
  320×240、640×480、1280×960，並針對標點換行、專有名詞及固定按鍵標籤做檢查。
- Shofixti 駕駛艙的 `DESTRUCT` 同步本地化為「自爆」。`ALT` 保留為實體按鍵
  名稱，`Project 6014` 與 `VUX` 保留官方專名／縮寫。
- Super Melee 戰鬥中的「船員／能量」仍使用較輕字重，但透明像素保留原版面板
  灰色；一般狀態不再出現黑底，低能量重著色效果也維持正常。
