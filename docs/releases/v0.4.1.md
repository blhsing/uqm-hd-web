# v0.4.1 — 開始選單全螢幕捷徑

這個修正版讓全螢幕啟動方式在 Windows 開始選單中清楚可見：

- 安裝器會在目前使用者的開始選單最上層建立
  `The Ur-Quan Masters HD - Traditional Chinese (Fullscreen)`。
- 捷徑使用主螢幕自動偵測的原生解析度、4x 繁中套件及全螢幕模式。
- 從舊版升級時，只在先前安裝 marker 證明所有權後移除舊的開始選單子資料夾捷徑；
  不會移除使用者自行建立的捷徑或其他檔案。
- 桌面全螢幕捷徑與安裝目錄內的 1280×960 視窗模式捷徑仍然保留。

遊戲內容及 4x 套件與 v0.4.0 相同。
