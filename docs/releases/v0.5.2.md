# v0.5.2 — 原生解析度戰鬥與捷徑圖示修正版

本版延續 v0.5.1 的原生 1920×1080 超取樣目標，修正超級對戰中只剩隨機閃爍星點、
雙方船艦消失的座標溢位，並修正 Windows 捷徑遺失圖示。

## 主要變更

- 原生解析度仍以 2560×1920 內部畫布繪圖，但戰鬥世界在解析度因子 3 時改用每顯示
  像素 2 個世界子單位。舊值 4 會產生 34,816×30,720 的轉場範圍及 69,632 的
  邏輯寬度，分別超過舊引擎的有號與無號 16 位元座標容量。
- 修正後的轉場範圍為 17,408×15,360，邏輯範圍為 34,816×30,720；高解析度圖形
  與字型不降級，船艦、星點、碰撞及鏡頭則保留在安全座標範圍內。
- 編譯期的船艦常數仍使用原有 4x 模板尺度；執行期由顯示尺寸推導的值才採用原生
  安全尺度，避免改變各船艦既有速度與武器資料。
- 桌面與「開始」功能表捷徑改用 `uqm.exe` 內嵌 Windows 圖示，不再指向套件內並
  不存在的 `icon.ico`。升級後的捷徑仍使用 `native1080-zh_TW`、解析度因子 3 與
  1920×1080 全螢幕參數。

## 驗證

- 67 項 Python 本地化、資產、輸入、原生戰鬥座標、封裝與安裝生命週期回歸測試。
- Windows PowerShell 管理式升級、11,473 個管理檔案的完整雜湊與兩個捷徑驗證。
- 12 秒 1920×1080 全螢幕煙霧測試，確認原生套件、解析度因子 3 與雙線性縮放。
- 實際進入繁中超級對戰並由玩家一、玩家二選船，確認雙方船艦在戰鬥區正常顯示；
  引擎日誌記錄 `transition_width = 17408, transition_height = 15360`。
- 「開始」功能表與既有工作列釘選均在安裝主機上核對為相同的繁中全螢幕參數及
  `uqm.exe,0` 內嵌圖示。
