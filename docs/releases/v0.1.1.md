# v0.1.1 — 修正高解析度 HUD 中文裁切

此維護版本修正 2x／4x 高解析度模式中，繁體中文字形超出固定 HUD
文字區域而被裁切或互相重疊的問題。發行 ZIP 不含原版遊戲或獨立的已修改
`uqm.exe`；請先從官方 SourceForge 專案取得 Windows Beta 1。

## 修正內容

- 4x 模式的太陽／星系名稱、日期與月份、船長、船長姓名、船名、燃料及
  船員欄位現在能完整顯示。
- 修正 2x 日期列頂端可能被裁切的問題。
- Tiny 與 StarCon 字格改為符合 SIS 固定文字帶的高度，同時保留
  Noto Sans TC Bold/700 的清晰筆畫。
- 新增字格設定及實際字形墨跡邊界的回歸測試，防止之後再次超出 HUD。
- 主選單、黃色選取脈衝、Super Melee `Esc`、繁中按鍵說明與既有翻譯
  均維持不變。

## 驗證範圍與限制

本版本通過 21 項本地化測試，以及安裝後 13 項完整驗證：11,530 個管理
檔案、三個 UQM 套件、五個捷徑及 4x 1920×1080 全螢幕煙霧測試。
另以實際新遊戲流程確認故事序幕能正常進入，並逐項檢查修正後的太陽、
日期、船長、船名、燃料與船員 HUD。

英文原聲沒有重新配音；少數執行檔硬編碼詞仍為英文；翻譯尚未完成逐句
母語人工校訂及完整劇情通關；網路 Super Melee 尚未驗證。
